SECCIÓN 04 — INTEGRIDAD

Propiedades ACID

A

Atomicidad

«Todo o nada». Si un paso falla al generar un pedido, el sistema ejecuta un ROLLBACK automático sin dejar registros incompletos.

C

Consistencia

La BD siempre mantiene un estado válido: claves primarias únicas, integridad referencial y restricciones de dominio.

I

Aislamiento

Cada transacción se comporta como si fuera la única ejecutándose. Previene «lecturas sucias» y condiciones de carrera.

D

Durabilidad

Tras un COMMIT, los datos se persisten en almacenamiento no volátil. Recuperación completa ante fallos catastróficos.

SQL TRANSACCIONAL

Implementación ACID en SQL

transaccion_pedido.sql 
BEGIN TRANSACTION;

-- Insertar cabecera del pedido
INSERT INTO PEDIDO
  (ID_Cliente, Fecha_Pedido, Estado)
VALUES (101, '2026-06-10', 'Pendiente');

-- Insertar detalle
INSERT INTO DETALLE_PEDIDO
  (ID_Pedido, ID_Producto, Cantidad)
VALUES (@NewID, 5, 2);

-- Descontar stock
UPDATE INVENTARIO
SET Stock_Actual = Stock_Actual - 2
WHERE ID_Producto = 5;

COMMIT;

🔄 BEGIN TRANSACTION

Marca el inicio de la protección de datos.

✅ COMMIT

Confirma todos los cambios de forma permanente. Garantiza Durabilidad.

↩️ ROLLBACK

Deshace todas las operaciones ante un error. Garantiza Atomicidad.

🛡️ TRY...CATCH

Monitorea cada sentencia y redirige a ROLLBACK automáticamente.

SECCIÓN 05 — SEGURIDAD

Seguridad en Bases de Datos

La seguridad en bases de datos protege la confidencialidad, integridad y disponibilidad de los datos almacenados.

🔴 Fuga de datos personales de miles de clientes
🟠 Manipulación de transacciones financieras
🟡 Robo de propiedad intelectual
🔵 Interrupción del servicio
⚪ Daño reputacional y sanciones legales

Principio de Mínimo Privilegio

Cada usuario solo tiene los permisos estrictamente necesarios para su función.

👤 Cliente_App
🎯 Agente_Ventas
📦 Gestor_Inventario
📊 Analista_Negocio
🔍 Auditor
⚡ DBA_Admin

AMENAZAS

Amenazas y Riesgos de Seguridad

👥

Amenazas Internas

Acceso no controlado de más de 400 startups asociadas al ecosistema de datos compartidos.

🤦

Error Humano

Cerca del 50% de los incidentes. Mala configuración en la nube, contraseñas débiles.

💉

Inyección SQL/NoSQL

Riesgo en aplicaciones web (Mi Store) y plataformas móviles (Mi Home) que interactúan con la BD.

🦠

Malware

Software malicioso dirigido a explotar vulnerabilidades en los SGBD de Xiaomi.

💾

Ataques a Backups

Copias de seguridad como objetivo de ransomware si no tienen los mismos controles estrictos.
